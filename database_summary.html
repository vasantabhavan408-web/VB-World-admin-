3. Key API Endpoints Querying this Database

  • GET /api/branches — Queries all Countries joined with active Locations.
  • GET /api/hero?page=home — Retrieves hero banner headline and image for specific page.
  • GET /api/menu — Retrieves full menu structure, category blocks, and dining experiences.
  • GET /api/branches/gallery — Fetches marquee images sorted by row and display order.
  • POST /api/auth/login — Authenticates against User table and returns signed JWT.
